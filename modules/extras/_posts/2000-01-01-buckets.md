# What are S3 buckets for?

An S3 bucket is a place for storing files on the cloud.  
S3 is the name of the storage system; an **S3-compatible** service works with the same tools as Amazon S3,
even when the storage is hosted by CLIMB or another provider.

In CLIMB, you can create and manage buckets using the [Bryn
interface](https://docs.climb.ac.uk/3.Getting-started/3.3.bryn/). You will
usually need the bucket's endpoint, name, access key, and secret key to use it
from another tool. Treat the secret key like a password.

![Bryn interface]({{ site.baseurl }}/{% link /img/bryn-buckets.png %})

## Using a graphical tool

You can browse, upload, download, and organise bucket contents with a file
transfer application such as [Cyberduck](https://cyberduck.io/). Cyberduck is
free software and is available for Windows and macOS.

Free or open-source alternatives include:

* [WinSCP](https://winscp.net/) for Windows. It is free and open source and
	can connect to S3-compatible storage.
* [rclone](https://rclone.org/) for Windows and Linux. It is free and open
	source; it is mainly a command-line tool.
  
When configuring a client, choose **Amazon S3** or **S3**, then enter the
CLIMB endpoint and your credentials. Do not use the default Amazon endpoint
unless your bucket is actually hosted by Amazon.

:bulb: when configuring a tool, remember to set the endpoint to `s3.climb.ac.uk`

## Using the command line

The AWS command-line tool can also work with S3-compatible storage. The
general form is `aws s3 ...`; add the CLIMB endpoint to commands when needed:

```bash
# List buckets
aws s3 ls

# List the files in a bucket
aws s3 ls s3://BUCKET-NAME/ 

# Copy a local file to a bucket
aws s3 cp results.txt s3://BUCKET-NAME/results.txt  

# Copy a file from a bucket to the current directory
aws s3 cp s3://BUCKET-NAME/results.txt .  
```

##  Nextflow

Nextflow supports S3 buckets natively, so you can specify input and output as s3 URIs:

```bash
nextflow run nf-core/pipeline \
    --input my_local_directory --outdir s3://myteam-bucket/
```
