# Introduction to RStudio

RStudio is an integrated development environment (IDE) for the R programming
language. It brings together a script editor, an interactive console, a file
browser, plots and help pages. This is convenient for bioinformatics because
we can write an analysis, run one part of it, inspect the result and return to
the code without changing applications.

![RStudio interface]({{ site.baseurl }}{% link img/rstudio.png %})

In this module we will use RStudio to explore the same microbial abundance
table used in the Python notebook examples. 
The complete example is available as 
`[jupyterlab/explore_table.Rmd]({{ site.baseurl }}{% link jupyterlab/explore_table.Rmd %})`. Here we introduce the ideas behind it; we
will not explain every line of the report.
