#### CLIMB websites

#### Linux command line refreshers

* [Unix training](https://astrobiomike.github.io/unix/) from AstroBioMike
* [Introduction to Bash scripting](https://telatin.github.io/microbiome-bioinformatics/Bash-tutorial-1/)
  
 
#### Python (using Jupyter notebooks)

* [Python for Beginners](https://www.python.org/about/gettingstarted/) — the official starting point, with introductory resources and installation guidance.
* [How to Use Jupyter Notebook](https://www.dataquest.io/blog/jupyter-notebook-tutorial/) from Dataquest — a practical walkthrough of notebooks, cells, Markdown, and running a first small Python analysis.

#### R and RStudio

* [R for Data Science](https://r4ds.hadley.nz/) — a free, approachable online book introducing R, RStudio, data wrangling, visualisation, and reproducible analysis.
* [RStudio User Guide: Get Started](https://docs.posit.co/ide/user/ide/get-started/) from Posit — a concise hands-on introduction to RStudio projects, scripts, packages, and plotting.
* [Posit Cheatsheets](https://rstudio.github.io/cheatsheets/) — useful one-page references once learners have begun using R and RStudio.
