## The Course

This is a short hands-on introduction to use the
**CLIMB** to perform bioinformatics analyses.

> :warning: This is **not** a bioinformatics training. We will use some
> bioinformatics-inspired scenarios to explore how CLIMB JupyterLab can be used
> in practice to perform a range of tasks.

![Outline image]({{ site.baseurl }}/{% link /img/climb-outline.svg %})

Some extra topics cover:

* S3 compatible buckets
* Nextflow (not a Nextflow training, just how it is integrated in CLIMB)
  
### Goal

- Walk through the JupyterLab interface
- Use the Linux Terminal to install packages and run analyses
- Understand the storage model
- Use Jupyter Notebooks to perform an analysis
- Use RStudio

### Prerequisites

- Linux command line
- Understanding Linux file system
- (optional) Basic coding skills in Python or R
