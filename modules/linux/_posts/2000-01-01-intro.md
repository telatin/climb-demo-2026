## Linux terminal

![Terminal lanucher icon]({{ site.baseurl }}/{% link /img/terminal.png %})

CLIMB notebook have a built in Linux terminal, that behaves in a similar way to common terminal emulators available on POSIX systems.

There are some key difference, that we will try to see now.


### Who are you

```bash
whoami
```

In a shared UNIX system, we have a unique username. This is **not** the case on CLIMB, where each member of a team (and in general, every CLIMB user), has the same Linux username: **jovyan** (a pun on Jupyter).

### Running some commands

A command will work as expected in any POSIX system:

```bash
ls -l
```

![screenshot]({{ site.baseurl }}/{% link /img/climb-ls.png %})

As you probably know, you can use multiple lines for a command using `\`. 
You will see this in the tutorial to make the website easier to read:

```bash
find /etc -type f -name "nextflow*" 2>/dev/null
```
is equivalent to:

```bash
find /etc \
   -type f \
   -name "nextflow*" 2>/dev/null
```
